# Mobile Scroll Story plan

**Status: in review.** Written 18 October 2026. One implementation PR. The owner approved the preset from the shortlist of five presets on 18 October 2026, and its live preview, and left the decisions in §2 open.

**Mobile Scroll Story** is the mobile size of Scroll Story: one tall mobile screenshot on a phone, read section by section. With it, every effect in the gallery comes in a desktop and a mobile size.

## 1. What is built

- `src/templates/scroll-story-template.ts`: one factory for both sizes, as `slider-template.ts` is for the sliders. The desktop size uses the browser window and a `desktop` slot. The mobile size uses the phone (quality bar §3.3) and a `mobile` slot. Both slots are required and `prefer: "tall"`. The slot key stays `desktop1` for the desktop size, so saved slot assignments still match.
- Same look and motion as Scroll Story: `single` layout, Fog, soft shadow, `pushIn` at intensity 0.2 with `smooth` easing and float 0.05, scroll stops `[0, 0.33, 0.66, 1]` with 0.8 s holds and `smooth` easing, no loop. The phone is 0.74 of the frame height at every aspect (§4: 70–78%).
- **Duration.** 10 s, or longer when the page needs it to stay under 0.9 screen heights per second (`minDurationFor`), rounded up to 0.5 s (`scrollStoryDuration`). At 10 s, `scrollPosition` ran the last move past the end of the shot, so the shot ended before the bottom of the page. The demo mobile pages need: Aurelia 9.6 s, Maison Oak 8.7 s, Studio Kova 8.5 s (all 10 s), Field Notes 10.4 s (10.5 s), Northwind 10.6 s (11 s). The brief's estimate of about 10.5 s for Aurelia was high. The rule applies to both sizes. Every desktop demo page needs 7.5 s or less, so Desktop Scroll Story's demo, preview and baselines don't change.
- `pairs.ts` pairs `scroll-story` with `mobile-scroll-story`, so the gallery suggests the size that fits the library (#41).
- Gallery preview: Aurelia's full mobile page (`demo-preview.ts`), generated by `npm run template-previews -- mobile-scroll-story`.
- Never cropped horizontally: the phone screen fits the 780 px capture to its width, and the page scrolls down to the footer (contact sheet, t85).

## 2. Decisions

| #   | Decision                                                              | Recommendation (built this way; open until the owner answers)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MS1 | Phone device, or the flat portrait card of the sliders and Frames     | **Phone**, as previewed. It is the mobile counterpart of Scroll Story's browser window, and a phone reads as someone scrolling a site. The card suits the multi-screen presets.                                                                                                                                                                                                                                                                                                                                                                                                             |
| MS2 | Rename Scroll Story to "Desktop Scroll Story", keep id `scroll-story` | **Yes**, as Frames plan D4 did for Desktop Frames. Saved projects, `public/templates/scroll-story.*` and the four `scroll-story-*` baselines don't change; only the card text does.                                                                                                                                                                                                                                                                                                                                                                                                         |
| MS3 | The camera pill covers page content                                   | The phone doesn't reserve the 5.5% status-bar safe zone that quality bar §3.3 describes. A capture without a status bar starts at the screen's top edge, and the page scrolls under the pill, as on a real phone. At the 0.66 hold and the last hold the pill sits on a line of text (`evidence/pill-at-holds-9x16.png`). **Recommended: fix it in its own PR**, because it changes every phone and the `device-phone-*` baselines: start the content below a 5.5% strip filled with the page's top-row colour. Ship Mobile Scroll Story as it is now. Listed in `docs/plan/follow-ups.md`. |
| MS4 | Visual baselines                                                      | 4 stills, as Scroll Story has: 16:9 and 9:16 at t = 0.8 s (the top of the page, end of the first hold) and 2.4 s (moving to the first stop). **They land only with the owner's written approval of the rendered stills.**                                                                                                                                                                                                                                                                                                                                                                   |
