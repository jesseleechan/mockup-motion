# Mobile Scroll Story plan

**Status: done.** Written 18 October 2026. One implementation PR, stacked on the iPhone PR #50. The owner approved the preset from the shortlist of five presets on 18 October 2026, and its live preview, and answered the decisions in §2 the same day.

**Mobile Scroll Story** is the mobile size of Scroll Story: one tall mobile screenshot on a phone, read section by section. With it, every effect in the gallery comes in a desktop and a mobile size.

## 1. What is built

- `src/templates/scroll-story-template.ts`: one factory for both sizes, as `slider-template.ts` is for the sliders. The desktop size uses the browser window and a `desktop` slot. The mobile size uses the phone (quality bar §3.3) and a `mobile` slot. Both slots are required and `prefer: "tall"`. The slot key stays `desktop1` for the desktop size, so saved slot assignments still match.
- Same look and motion as Scroll Story: `single` layout, Fog, soft shadow, `pushIn` at intensity 0.2 with `smooth` easing and float 0.05 (Float was cut on 26 October 2026), scroll stops `[0, 0.33, 0.66, 1]` with 0.8 s holds and `smooth` easing, no loop. The phone is 0.74 of the frame height at every aspect (§4: 70–78%).
- **Duration.** 10 s, or longer when the page needs it to stay under 0.9 viewport heights per second (`minDurationFor` with `scrollableFramesFor`), rounded up to 0.5 s (`scrollStoryDuration`). At 10 s, `scrollPosition` ran the last move past the end of the shot, so the shot ended before the bottom of the page. On the phone the viewport is the screen below the status bar (#50), so the demo mobile pages need: Aurelia 10.2 s (10.5 s shot), Northwind 11.3 s and Field Notes 11.0 s (11.5 s), Maison Oak 9.2 s and Studio Kova 9.0 s (10 s). The rule applies to both sizes. Every desktop demo page needs 7.5 s or less, so Desktop Scroll Story's demo, preview and baselines don't change.
- `pairs.ts` pairs `scroll-story` with `mobile-scroll-story`, so the gallery suggests the size that fits the library (#41).
- Gallery preview: Aurelia's full mobile page (`demo-preview.ts`), generated by `npm run template-previews -- mobile-scroll-story`.
- Never cropped horizontally: the phone screen fits the 780 px capture to its width, and the page scrolls down to the footer (contact sheet, t85).
