## Running Safari and Firefox

The automated suites only cover Chromium (`playwright.config.ts` defines `chromium`, `visual` and `perf` projects). Firefox and Safari need a manual pass. Record the result as a new column in the table above, with the browser version and the date.

### Setup (once)

1. Install Node.js 22.12 or later.
2. Clone the repo, then run:

   ```sh
   npm ci
   npm run dev
   ```

3. Open http://localhost:3000 in the browser under test. On macOS, Safari 17 or later is needed for WebGL2 in workers and WebCodecs. Use current Firefox.

### Checklist (about 20 minutes per browser)

Do these in a fresh profile or private window, so storage starts empty. Keep the developer console open and note any errors.

1. **First run.** The template gallery opens. Close it and click "Try with demo content". The stage shows an upright Aurelia browser with correct colours (compare with `docs/fix-plan/evidence/F11/after/quiet-hero.png`).
2. **Playback.** Press Play. The push-in is smooth, never reverses, and loops.
3. **Templates.** Open the template gallery and apply Responsive Pair, Isometric Wall and Launch Reel. Every screen shows a real screenshot (no black screens) and nothing is upside down.
4. **Upload.** Drag a PNG from the desktop onto the stage. It appears in the Media tab. Drag it from the Media tab onto the device on the stage; the device shows it.
5. **Music.** Click "Add music" and choose a short MP3. The waveform appears. Play: the music starts with the video. Seek twice; the music follows.
6. **Export MP4.** Export, Custom, MP4, 720p. Note whether the result says "Verified MP4" or the dialog falls back to WebM. Download the file and play it in the system player: upright, correct colours, music audible.
7. **Export web bundle.** Export, Website, 720p. The zip holds an MP4 and/or a WebM, a `-poster.webp` and `embed.html`. Open `embed.html` next to the videos in the same browser; the video autoplays muted and loops.
8. **Export GIF.** Export, Custom, Animated GIF. It finishes and plays in the browser.
9. **Cancel.** Start a 1080p export and click "Cancel export" at about 50%. The editor stays usable.
10. **Reload.** Reload the page. The project, its screenshots and the music are still there (IndexedDB).
11. **Colour picker.** In the Video inspector, open the background colour field. If the browser has no `EyeDropper` API (Firefox, Safari), the eyedropper button is hidden.
12. **Embed snippet.** After a bundle export, click "Copy code" and paste it into a text editor.

If a step fails, note the browser version, the step and the console error, and add it to [`follow-ups.md`](follow-ups.md).

### Edge

Edge is Chromium-based, so the Chrome results above are likely to hold, but it has never been run. To check it, run the same checklist in Edge.
